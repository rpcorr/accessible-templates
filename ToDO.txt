1. Registration Form

- Collecting personal information through different form controls.
- Required fields and form validation.
- Displaying accessible error messages and feedback.
- Grouping related choices using radio buttons and checkboxes.
- Submitting a form with clear user feedback.

2. Search and Results Page
Components: Search Combobox, Pagination, Breadcrumbs and Status.

Demonstrates:
- Searching and filtering content using an interactive search field.
- Displaying search results across multiple pages.
- Providing clear navigation through breadcrumbs.
- Communicating result status, such as loading, no results or completed searches.
- Maintaining keyboard accessibility throughout the search experience.

3. Financial Dashboard
Components: Data Table, Tabs, Progress Indicator and Toast.

Demonstrates:
- Presenting financial information in an organized data table.
- Grouping dashboard information into separate tabbed sections.
- Displaying financial goals, budgets or savings progress.
- Providing temporary feedback for completed actions.
- Making financial information easier to scan and understand.

Demonstrates:
- Selecting individual dates and date ranges.
- Choosing available appointment or booking times.
- Guiding users through a multi-step booking process.
- Validating booking information before proceeding.
- Reviewing booking details before final submission.

Components: Switch, Disclosure, Radio Group and Button.

Demonstrates:
- Managing account and application preferences.
- Enabling and disabling settings using switches.
- Expanding and collapsing additional settings information.
- Selecting one option from a group of preferences.
- Saving changes with clear keyboard and screen-reader feedback.

Components: Text Input, Textarea, Select, File Upload, Alert and Button.

Demonstrates:
- Collecting contact information and support requests.

Components: Data Table, Search Box, Select, Checkbox, Pagination, Modal and Toast.

Components: Badge, Tabs, Card, Button, Pagination and Alert.

Demonstrates:
- Displaying unread and read notifications.
